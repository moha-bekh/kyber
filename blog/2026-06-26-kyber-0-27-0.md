Kyber 0.27.0 brings OpenID Connect (OIDC) authentication to the web client, extending the identity-provider integration introduced for the server and desktop client in 0.26.0. The web client also gains live metrics and an automatic reconnection toggle in the connection UI. On the desktop side, automatic reconnection can now be enabled with the `--auto-reconnect` command-line flag.

Server configuration is more flexible, with additional ways to set controller parameters and a `KYBER_CONFIG` environment variable to override the configuration file used by `kyservice`, `kycontroller`, `kyavserver`, and `kynputserver`. Building on the X11 clipboard support added in the previous release, this release enables clipboard handling on the server side.

Several fixes improve startup and shutdown behaviour. The Windows service fixes an intermittent issue where Windows rejected controller startup, and the desktop client now exits when it receives a stopped event regardless of the reason. Child processes managed by `libkypc` are now automatically terminated when their handles are dropped. The media dependency build also moves to Meson.
