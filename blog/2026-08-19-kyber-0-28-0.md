Kyber 0.28.0 adds macOS server support and a new avconv backend for the audio/video service. Linux capture gains Wayland display geometry discovery, while DRM device initialisation failures are now logged once per device instead of on every poll. The encoder setting in `kyber_config.toml` is now optional and defaults to NVENC.

Building on the live metrics introduced in 0.27.0, the web client now allows metrics to be downloaded at any time and buffers JSON writes to avoid losing metrics at high reporting rates. Both clients improve metrics handling by moving it out of the main loop, replacing assertions with warnings, and stopping unused metrics tasks after disconnection.

The desktop client now blocks clicks outside the video area and uses the new Kyber brand mark for its application icon. The server tray only reports a connected state once a streaming session is established, and its menu now shows the server version. Startup logs report the correct revisions, and the client gains a `--version` option to log its revision, making troubleshooting easier.

Internally, the transport layer gains cancellation-safe send and receive operations, shared serialisation code, and preallocated buffers for merging datagram segments. The input C API reduces its use of unsafe code and improves handling of null pointers. Logging is also unified around `log4ky` in the SDK and client.
