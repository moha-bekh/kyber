Kyber 0.29.0 adds an agent and heartbeat mechanism to report host availability, token exchange and renewal for authenticated connections, and a kyber:// URL scheme to launch the desktop client from a link. These features prepare Kyber for compatibility with a future management portal.

**Native WebSocket support** is now available in the desktop client. The WebSocket implementation has also been refactored around a multi-backend architecture, sharing the transport abstraction between browser and native implementations.

The **macOS server is now fully packaged**, simplifying distribution and installation. This will allow us to release a fully operational, signed package soon.

**x264 now supports 4:4:4 encoding**, including through the avconv backend, preserving fine colour detail in text and desktop content. The previous automatic 1920-pixel downscaling has also been removed, allowing software encoding at the source resolution.

The **avconv pipeline gains a GStreamer capture wrapper**, alongside hardware-device selection, frame-handling and encoding-latency improvements. Together, these changes enable more targeted optimisation for Raspberry Pi and other embedded platforms.
